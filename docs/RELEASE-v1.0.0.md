# 盈刻 YINK v1.0.0

首个公开开源版本，以 MIT License 发布项目自身代码。

## 体验

- 在线使用：https://leekquant.tech/
- 离线使用：下载 YINK-offline.zip，解压后用普通浏览器打开 YINK/index.html。
- 无需前端构建、账号或 API Key；示例 CSV 可离线体验。

## 包含功能

- A 股、港股、美股搜索及 CSV 导入，5 分钟／小时／日／周 K。
- 多笔买卖节点、成交价与数量、移动平均成本计算。
- 标准轨迹、水墨蜡烛、水墨折线及自定义标点。
- 自定义画布比例、文字、图片、墨点素材、图层操作和撤销／重做。
- 离线字体、自定义字体，PNG 导出及项目 JSON 保存。
- 手机适配、中英文、深浅色主题和界面字号设置。
- 可选管理端：日期统计、IP 备注、限制、CSV 导出及操作记录。

第三方字体与库保留各自许可证。行情接口可能变化或受限；可用 CSV 继续编辑。本工具不提供预测或下单，收益计算不计手续费、税费、汇率和分红。

## English

YINK turns stock price history and optional trade markers into editable art posters. Choose standard charts or expressive ink strokes, compose with text, images, and layers, then save your work locally.

**Use the live app immediately: https://leekquant.tech/** — no signup or installation required.

For offline use, download `YINK-offline.zip`, extract it, and open `YINK/index.html` in your browser. Bundled fonts, stickers, and the fictional CSV sample work offline; online market data requires a network connection.

This release includes multiple trade markers and moving average cost calculations, standard and ink chart styles, custom canvas ratios, layered editing, PNG export, project JSON, mobile support, light/dark themes, and a Chinese/English interface. The optional admin backend includes reports, IP notes, access restrictions, and CSV exports.

The repository includes Chinese and English project introductions, real interface images, example artwork, and detailed acknowledgements. Thank you to LingDong- (Squiggy), Alejandro Campos Uribe (p5.brush), Warren2060 (Chill G Sans), and all font authors and contributors.

YINK's own code uses MIT; third-party libraries and fonts retain their licenses. Market-data availability may vary. Returns exclude fees, taxes, exchange rates, and dividends. YINK does not predict prices or place trades.
